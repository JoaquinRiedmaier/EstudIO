Gestión de Materias

Organización completa de asignaturas anuales o cuatrimestrales. Incluye eliminación en cascada limpia de apuntes y recordatorios asociados.

✍️

Editor TipTap + Pegado Nativo

Editor WYSIWYG basado en TipTap que almacena todo en Markdown real (.md). Pegá capturas desde el portapapeles (Ctrl+V) para guardarlas en carpetas locales.

⏰

Recordatorios y Alertas

Agenda inteligente para entregas y exámenes con cálculo de alertas automáticas (desde 1 hora hasta 1 mes antes) y resumen diario en el panel de hoy.

📅

Mini-Calendario Interactivo

Visualizador mensual integrado en la barra lateral que marca tus eventos importantes para que nunca pierdas una fecha de examen o entrega.

☁️

Sincronización Google Drive

Backup automático en la nube. Creá copias en formato ZIP o autentícate con Gmail para restaurar tu información si cambiás de computadora.

🎓

Horarios Universitarios

Diseñá tu grilla semanal de cursada indicando materia, día, horario y aula. Exportá e importá tus horarios en JSON para compartirlos con compañeros.

💡 ¿Por qué elegir EstudIO?

✓

Todo en un solo lugar

Evitá fragmentar notas, agendas y carpetas. EstudIO reúne todo en una interfaz tipo libreta académica.

🔒

Privacidad y Velocidad Local

Construido con Rust (Tauri) y SQLite. El consumo de RAM es mínimo y tus archivos se guardan en tu disco.

📂

Sin formatos propietarios

Tus apuntes son archivos .md reales. Podés abrirlos con Obsidian, VS Code o cualquier editor de texto.

🎨

Diseño Editorial Agradable

Estética tipo papel cálido con verde biblioteca, distracción reducida y colapsado automático de menú lateral.

🛠️ Arquitectura & Tecnologías

🦀 Rust + Tauri v2

Backend ultrarrápido y seguro. Administra el sistema de archivos local, diálogos y portapapeles nativo.

⚡ HTML5 & TypeScript

Frontend liviano y modular en Vanilla TypeScript con compilación ultrarrápida mediante Vite.

🗄️ SQLite (mi_DB.db3)

Base de datos relacional local sin servidor para almacenar materias, eventos y metadatos con máxima velocidad.

📝 TipTap (ProseMirror)

Motor de edición extensible con soporte WYSIWYG y exportación directa a formato Markdown estándar (.md).
